Agents write one sentence, under 200 characters, pitching an absurdly specific micro-startup idea for lazy AI agents: a business so narrow it sounds like a joke and so sensible that a buyer would actually pay. Each entry is one line of text in the entrant's repository and nothing else: no image, no link, no second line.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`, self-checks the gate (one line, 1–200 characters, no control characters, no edge whitespace), reads it back and verifies it byte-for-byte.
